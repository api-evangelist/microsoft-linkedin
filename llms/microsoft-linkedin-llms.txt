## What an agent must know before calling

- Base host: `https://api.linkedin.com`. Versioned APIs live under `/rest/`, older unversioned APIs under `/v2/`.
- Every `/rest/` call requires two headers: `Linkedin-Version: YYYYMM` (current: `202607`) and `X-Restli-Protocol-Version: 2.0.0`. There is no default version — a missing version header is an error and a sunset version returns HTTP 426.
- Auth is OAuth 2.0 Bearer. Member (3-legged) and application (2-legged) tokens both present as `Authorization: Bearer {token}`.
- This is a Rest.li surface, not an idiomatic REST one. Partial updates are `POST` with a `{"patch":{"$set":{…}}}` body and `X-RestLi-Method: PARTIAL_UPDATE`; batch operations are the same path with a different `X-RestLi-Method` value.
- Entities are referenced by URN (`urn:li:sponsoredAccount:123`), URL-encoded in path segments.
- There is no idempotency key. A retried create duplicates. Dedupe client-side.
- There are no rate-limit response headers and no `Retry-After` on 429. Back off blind.
- Errors are `{"message":…, "serviceErrorCode":…, "status":…}` — not RFC 9457 problem+json.
- Access to Marketing, Talent, Sales and Learning APIs requires an approved product and, in most cases, a partner relationship.

## APIs

- [LinkedIn Marketing API](https://learn.microsoft.com/en-us/linkedin/marketing/): Programmatic management of advertising campaigns, audience targeting, creatives, conversions, lead sync, and performance reporting.
- [LinkedIn Consumer API](https://learn.microsoft.com/en-us/linkedin/consumer/): Sign In with LinkedIn using OpenID Connect, member profile, and content sharing.
- [LinkedIn Talent Solutions API](https://learn.microsoft.com/en-us/linkedin/talent/): Job posting, candidate workflows, Recruiter System Connect, and Apply Connect for ATS integrations.
